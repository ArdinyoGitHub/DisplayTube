# Store listing: English (en-US)

## App name (max 30 characters)
DisplayTube: USB Second Screen

## Short description (max 80 characters)
Use your phone as a second screen for your PC over a USB cable.

## Full description (max 4000 characters)
DisplayTube turns your Android phone into an extended second display for your Windows or Linux computer over a USB cable. No Wi-Fi or internet needed; the picture travels over the cable only.

⚠️ IMPORTANT: This app does not work on its own. You need to install the free, open-source DisplayTube program on your computer:
https://github.com/ArdinyoGitHub/DisplayTube/releases
Without the computer program, the app only shows a "Waiting for computer" screen.

HOW IT WORKS
• The computer program adds a virtual monitor to Windows or Linux.
• That screen is encoded as H.264 on your graphics card and sent to the phone over the USB cable (adb).
• DisplayTube on the phone shows it full screen using the hardware decoder.

FEATURES
• USB cable only: no Wi-Fi, mobile data or local network is used.
• Low latency: hardware encoding and decoding.
• Works with AMD, NVIDIA and Intel graphics, including integrated graphics.
• Reconnects automatically when the cable is unplugged and plugged back in.
• No ads, no account, no data collection. Open source (MIT license).

REQUIREMENTS
• A phone with Android 8.0 or later and a USB data cable
• Windows 10 (2004+) / Windows 11 64-bit, or a Linux computer
• "USB debugging" must be enabled on the phone (Settings > About phone > tap Build number 7 times, then Developer options > USB debugging).

SETUP
1. Download and run the computer program from the address above.
2. Connect the phone over USB and accept the "Allow USB debugging" prompt.
3. Open DisplayTube on the phone; the picture appears within a few seconds.

KNOWN LIMITATIONS
• Display only for now; you cannot control the computer by touching the phone.
• No audio.

Source code, questions and bug reports: https://github.com/ArdinyoGitHub/DisplayTube
